To paste from a buffer into a terminal buffer:

    1.  Yank text from normal buffer
    2.  Enter terminal-job mode with `i` or `a`
    3.  Paste using `Ctrl-W " "`

Multi-repeat

    `:global /pattern/` starts at first column of each matching line


Edit contents of macro in register `m`

    1.  Go to blank line and paste macro using `"mp`
    2.  Edit the text
    3.  Yank text back into register using `"myy`
